# CLASSICALENDER (클래시캘린더)

> 대한민국 클래식 공연 일정 큐레이션 & 애호가 커뮤니티 플랫폼  

---

## 🎻 주요 기능

1. **다차원 클래식 공연 탐색 (Discovery & Curation)**
   - **날짜별**: 월별 인터랙티브 캘린더 뷰, 당월/기간별 필터
   - **장소별**: 예술의전당 콘서트홀, 롯데콘서트홀, 세종문화회관 대극장, 부천아트센터, 아트센터인천, 통영국제음악당, 대구콘서트하우스 등
   - **연주자 / 단체별**: 서울시립교향악단, KBS교향악단, 베를린 필하모닉, 조성진, 임윤찬, 클라라 주미 강, 백건우 등
   - **작곡가 / 작품별**: 쇼팽, 라벨, 말러, 베토벤, 라흐마니노프, 바흐, 브람스, 차이콥스키 등
   - **뷰 모드**: 정갈한 카드/리스트 모드 & 월별 인터랙티브 캘린더 모드

2. **크롤링 차단 대응 및 수동 등록 관리자 센터 (Admin)**
   - 주요 연주장 홈페이지 수집망 실시간 모니터링 
   - 전체 수집망 1-클릭 동기화 시뮬레이션

3. **자유 커뮤니티 (공연 기대평 & 관람 후기)**
   - 실시간 공감(좋아요), 댓글 등록, 실시간 상태 동기화
---

## 🛠️ 실행 및 빌드

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 7-Gate 무결점 자동화 검증 스크립트 실행
npm run test:qa
```
